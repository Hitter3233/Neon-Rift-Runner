NEON RIFT RUNNER — GLOBAL LEADERBOARD UPDATE

WHAT'S NEW
- A Hall of Fame / leaderboard screen
- Player display names
- Automatic score submission when a run ends
- Global top-10 scores when connected to Supabase
- Local personal-best fallback before online setup is complete

IMPORTANT
The global leaderboard will NOT work for all players until you create a Supabase project and add its URL and anon/public key to index.html. Those values are intentionally placeholders; I cannot create or access your database from this chat. Never put a Supabase service_role key in browser code.

SET UP THE SHARED LEADERBOARD
1. Create a project at https://supabase.com/ and open its SQL Editor.
2. Run this SQL to create the leaderboard table and public read/submit policies:

create table if not exists public.scores (
  id bigint generated by default as identity primary key,
  player_name text not null check (char_length(player_name) between 1 and 18),
  score integer not null check (score >= 0 and score <= 100000000),
  shards integer not null default 0 check (shards >= 0 and shards <= 1000000),
  created_at timestamptz not null default now()
);

alter table public.scores enable row level security;

grant select, insert on public.scores to anon;

create policy "Anyone can read leaderboard scores"
on public.scores for select to anon
using (true);

create policy "Anyone can submit a score"
on public.scores for insert to anon
with check (
  char_length(player_name) between 1 and 18
  and score >= 0 and score <= 100000000
  and shards >= 0 and shards <= 1000000
);

3. In Supabase Project Settings / API (or Connect), copy the Project URL and anon/public key. Do NOT use the service_role key.
4. Open index.html in a text editor and find:
   const LEADERBOARD_CONFIG={supabaseUrl:'YOUR_SUPABASE_PROJECT_URL',supabaseAnonKey:'YOUR_SUPABASE_ANON_KEY'};
5. Replace the two placeholder strings with your actual Project URL and anon/public key. Keep the quotes.
6. Upload the updated index.html and README to your game's hosting / PPU Studio workflow, if it accepts standalone HTML and browser JavaScript.

HOW IT WORKS
- Players choose a display name the first time they submit a score; it is saved in that browser.
- The game submits the score and shards at the end of a run.
- The Hall of Fame displays the ten highest submitted scores across all players using the same Supabase project.

SECURITY LIMITATION
This starter leaderboard allows public score submissions. Client-side games can be modified, so players could fake scores. The SQL checks basic bounds, but does not prove a score was legitimately earned. For a competitive/production leaderboard, submit scores through a server-side function that validates gameplay or use signed run results, rate limits, and moderation. Never expose a service_role key in the game.

RUN LOCALLY
Open index.html in a modern browser. No build tools or dependencies are required. Without Supabase configured, the game runs and the leaderboard displays a local-device fallback, not a true global leaderboard.
