NEON RIFT RUNNER — PROFILE & OUTFIT SHOP

Upload index.html to the root of your GitHub Pages repository.

Features:
- Username profile menu; change username any time.
- Outfit shop with previews, coin prices, buying and equipping.
- Coins earned from collecting coins and completing runs.
- Saves username, coins, owned outfits, equipped outfit and best score in this browser using localStorage.
- No Supabase, GitHub API, leaderboard, external libraries, or backend.

Note: Progress is saved per browser/device. Clearing browser data or switching devices resets local progress.
Controls: SPACE, UP ARROW, or tap the game to jump.
